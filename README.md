# Privacy-Preserving Nuclei Segmentation & Tissue Classification

## Overview
AI-powered medical image analysis using Deep Learning and Federated Learning.

## Features
- U-Net nuclei segmentation
- Tissue classification
- Federated Learning (Flower, PySyft)
- Streamlit interface

## Technologies
Python, PyTorch, OpenCV, MONAI, Flower, PySyft, Streamlit

## Dataset
The PanNuke dataset is not included in this repository because of its size.

## Installation
```bash
pip install -r requirements.txt
python main.py
```
